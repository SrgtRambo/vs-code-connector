Settings

Local model settings and data handling.

Local Ollama provider

When enabled, the local model drafts architecture and generates application source files. When disabled, Forge uses its clearly labeled offline starter templates. Model-generated source is validated and never written outside the folder you choose. Ollama and the local Forge server must be running for AI requests. If Forge reports that its local API is unavailable, start or restart Start Forge AI.command, then refresh this page.

NOT CHECKED
Ollama is installed locally. Check connection & models to verify the service. AI source generation now builds the page, styles, and behavior in separate resumable steps; live generated-app quality is being verified.
